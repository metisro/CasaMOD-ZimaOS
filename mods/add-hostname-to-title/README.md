# Add Hostname to Title

Adds the current access hostname and port to the dashboard page title, making
multiple ZimaOS hosts easier to distinguish.

- Original author: [Cp0204](https://github.com/Cp0204)
- Original source: [CasaMOD add-hostname-to-title](https://github.com/Cp0204/CasaMOD/tree/main/app/mod/add-hostname-to-title)
- ZimaMOD status: Tested compatible without source changes
- MOD Store category: Compatible with ZimaMOD created for CasaMOD
