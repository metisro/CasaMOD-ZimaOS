# Network Title Setter

Detects whether the dashboard is accessed through an internal or public
network and sets the page title using customizable network and system labels.

- Original author: MingTechpro
- Original source: [CasaMOD network-title-setter](https://github.com/Cp0204/CasaMOD/tree/main/app/mod/network-title-setter)
- ZimaMOD adaptation: Chinese comments and default network labels translated
  into English
- MOD Store category: Compatible with ZimaMOD created for CasaMOD
